First launch

From download to your first board

Start with the official download at the top of this page. A copy of this illustrated guide is included with the installer and works offline.

1

Open the installer

If you downloaded a ZIP, double-click it to extract the folder first. Then double-click the Canvas DMG. If you opened this guide from the mounted disk image, that step is already done.

The download includes third-party notices and source materials. Keep them with the package; they do not need to be installed.

2

Drag Canvas into Applications

In the installer window, drag the Canvas icon onto the Applications folder. Wait for copying to finish. Then open Finder → Applications → Canvas.

Canvas is separate from the personal Canvas V5 edition (previously Canvas Vault). Upgrading from Canvas Core? Quit Canvas Core and back up its library first. Install and open Canvas, then check your existing content is present. Both names use the same existing Core library; after checking, remove only the old Canvas Core.app from Applications so you do not open a stale copy. Keep your library folders and backup.

3

If Apple cannot verify the app

This early preview is not Apple-notarized. Your Mac may block it before it opens. Only continue if you trust this official download and want to approve it.

A different warning? If it says the app is damaged, will damage your computer, or malware was detected, stop and report the exact message through the feedback link below. These steps are for the verification warning shown above.

Approve Canvas in macOS

  1. After the blocked launch, open System Settings → Privacy & Security.
  2. Scroll to the security section. Find the blocked Canvas message and choose Open Anyway.
  3. Confirm Open when prompted. Authenticate on your Mac if it asks.

You are approving this app yourself. This page cannot install software or change security settings. You do not need to disable system-wide protection.

4

Make it yours

Wait for Canvas to open its local library. A starter library and Watch Later are expected. Create a Swipe Board, add a note, and drag in an image or PDF.

Quit Canvas with Command-Q, then reopen it from Applications. Check that your board, note and files are still there. You can eject the installer disk image after installation.

Inside Canvas

A home for what you collect and learn

Swipe Boards

Organize references, notes, PDFs, images and saved media around a project.

Kanban Boards

Arrange ideas, notes and tasks in columns with cards you can complete.

Discover & Watch Later

Follow supported creators, save useful material and keep sources to revisit. Loading online feeds needs internet access.

Whiteboards

Sketch and arrange visual ideas with the built-in Excalidraw workspace.

Complete-library export and restore are included. Studio editing, portable single-board sharing and automatic Canvas Vault import are not.

If something gets in the way

I cannot find Open Anyway

Try opening the installed Canvas app once more, then return to Privacy & Security. If the option is still missing or disabled, report the problem through the feedback link below. A work- or school-managed Mac may restrict this option.

The app opens, but shows an error

Record the exact message, your Mac model and macOS version. Include them in a bug report using the feedback link below. Crop personal information from screenshots. Never send passwords, your full library or unredacted logs.

Will everything work offline?

Saved local notes and files work offline. Web capture and creator feeds need internet access and depend on their providers. Optional speech transcription requires an additional module and model; they are not included in this installer.

How do I get updates?

This preview uses manual updates. There is no automatic update feed. Future releases will be listed on Canvas. Back up your library before installing an update.

What if I already installed Canvas Vault?

Keep it. Canvas has a different application identity and library. It does not replace your original app. Do not point Core at your Vault library during this preview.

How do I uninstall Canvas?

Move Canvas from Applications to Trash. Its separate library stays on your Mac. Deleting that library would erase its content, so do that only if you intentionally want to remove your data.
