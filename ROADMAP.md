# Canvas roadmap

Status updated: September 13, 2026. This is a direction of travel, not a release schedule or delivery promise.

| Area | Status | Intended outcome |
| --- | --- | --- |
| Community feedback | Available | Read about Canvas, report bugs, and explain feature needs. |
| Apple Silicon Mac preview | Available; recipient testing continues | Install a focused research and notes workspace and verify that work survives quitting and reopening. |
| Public installer | 0.1.1 preview.2 | Download an ad-hoc signed early build with clear compatibility, installation instructions, and licensing information. |
| Complete-library recovery | Available | Export and restore a complete library, including media and workspace data. |
| Portable board export/import | Planned, not available | Move a selected board between libraries without sharing an entire private library. |
| Update infrastructure | Future setup | Provide a clear, verified path to newer approved builds. |

The current preview focuses on Swipe, Kanban, Discover, Whiteboard and Watch Later workflows. Studio editing and portable single-board sharing remain outside this edition. Priorities may change as pilot evidence and community feedback arrive.

[Suggest an improvement](https://github.com/OsirisMedici/canvas/issues/new?template=feature_request.yml) by explaining who it helps and what would become easier.
