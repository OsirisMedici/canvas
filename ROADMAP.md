# Canvas V5 roadmap

Status updated: September 12, 2026. This is a direction of travel, not a release schedule or delivery promise.

| Area | Status | Intended outcome |
| --- | --- | --- |
| Community feedback | Available | Read about Canvas V5, report bugs, and explain feature needs. |
| Apple Silicon Mac preview | Available; recipient testing continues | Install a focused research and notes workspace and verify that work survives quitting and reopening. |
| Public installer | 0.1.1 public preview | Download an approved build with clear compatibility, installation instructions, and licensing information. |
| Portable board export/import | Planned, not available | Move a selected board between libraries without sharing an entire private library. |
| Update infrastructure | Future setup | Provide a clear, verified path to newer approved builds. |

The current Core preview focuses on Swipe, Brain, Learning, Goal, and Watch Later workflows. Drawing and Studio editing are outside that edition. Priorities may change as pilot evidence and community feedback arrive.

[Suggest an improvement](https://github.com/OsirisMedici/canvas-v5-public/issues/new?template=feature_request.yml) by explaining who it helps and what would become easier.
